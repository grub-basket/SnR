## 0.5.14

Mobile compatibility.

- **Fix: plugin could fail to load on some mobile devices.** The bundle is now
  compiled to `es2018` (down from `es2020`, matching Obsidian's own sample
  plugin). Older mobile webviews could fail to *parse* newer syntax, which
  surfaced as "this plugin failed to load" on the device while working fine on
  desktop.
- **Fix (mobile): zoom +/- buttons rendered as invisible 0px-wide icons.**
  Obsidian's mobile stylesheet pads every button; the icon buttons' geometry is
  now restated under `.is-mobile` so the +/- controls show correctly.
