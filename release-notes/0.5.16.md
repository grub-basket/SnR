## 0.5.16

Store-review compliance.

- **Raised `minAppVersion` to 1.7.2.** The plugin awaits `Workspace.revealLeaf`,
  whose Promise-returning form was introduced in Obsidian 1.7.2; declaring 1.7.0
  tripped the `obsidianmd/no-unsupported-api` check. 1.7.2 is still well below
  current stable and mobile Obsidian, so this changes nothing for users.

No functional changes to the plugin since 0.5.15.
