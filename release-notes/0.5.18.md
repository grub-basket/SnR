## 0.5.18 — 2026-10-02

Mouse and keyboard improvements for drawing covers and moving around the image list, requested by a user.

### Drawing covers

- **Draw over existing covers.** While Rectangle or Polygon mode is on, existing covers (and their handles, vertices and overlays) are click-through, so a new cover can start or finish on top of an old one. Previously the finishing click landed on the old cover and was ignored. To select or move an existing cover, leave draw mode first.
- **Enter finishes the shape being drawn.** For a rectangle it commits at the current mouse position, as an alternative to the second click. For a polygon it works like Finalize or double-click.
- **Right-click cancels the shape being drawn.** It discards the rectangle's first corner or the polygon points placed so far, and suppresses the context menu. Draw mode stays on. With nothing being drawn, right-click behaves as before.
- **Esc cancels the shape being drawn.** Esc was already blocked from switching tabs inside the view, but it did nothing else. It now cancels the draft, and still never switches tabs. Both Esc paths (the keymap scope and a document capture listener) share one handler, deduplicated per key press.
- Polygon points and rectangle corners respond to the left mouse button only, and not to macOS Ctrl+click, which is a right-click. Right- or middle-button presses no longer add stray polygon points or start a rectangle.
- The notice shown when drawing a target region no longer says Esc is disabled. It now reads "then Finalize or press Enter. Right-click or Esc cancels."
- Cancelling a polygon keeps the image's blue drafting outline (and click-through covers) while the image is still in a draw mode.

### Navigation

- **Hold the middle mouse button and drag to pan** the image list in any direction, like the hand tool in a PDF viewer. Handy when zoomed past 100%, where the mouse wheel over an image steps the reveal instead of scrolling. A grabbing cursor shows during the drag. The middle press never moves or resizes the cover under the cursor, and the drag ends cleanly even if the button is released outside the window. On Windows and Linux the autoscroll widget is suppressed.

### Docs

- The README's Drawing section now describes rectangle drawing correctly (click a corner, move, click the opposite corner). It also covers Enter, right-click and Esc, and the click-through behaviour. The keyboard table gains Enter and an updated Esc row, plus a note on mouse controls.
- The Rectangle and Polygon button tooltips mention Enter to finish and right-click or Esc to cancel.
- Release metadata: version 0.5.18 in `manifest.json` and `package.json`, a `versions.json` entry (minAppVersion unchanged at 1.7.2), and a CHANGELOG entry.
- Internal developer notes were updated to match the new Esc behaviour and mouse controls. They are not part of this repository.
