## 0.5.15

Packaging fix for the community-store build check.

- **Regenerated `package-lock.json`** — the committed lockfile had drifted
  badly out of date (it still named the plugin `image-annotator` at `0.2.0`
  with the original dependency set), so `npm ci` refused to install. The
  lockfile now matches `package.json`, and a clean `npm ci && npm run build`
  passes.

No functional changes to the plugin since 0.5.14.
